df = pd.read_csv('data/covid_data_raw.csv') print(df.info()) print(df.isnull().sum())
STEP 02

Data Cleaning & Imputation

Standardizes ISO country naming, converts mixed date string variants to ISO-8601, and fills reporting omissions.

df['country'] = df['country'].str.strip() df['date'] = pd.to_datetime(df['date']) df.fillna({'new_cases': 0}, inplace=True)
STEP 03

Data Validation & Deduplication

Validates chronological monotonicity per country, ensures zero negative counts, and enforces composite primary key uniqueness.

df = df.drop_duplicates(subset=['date', 'country']) assert (df['new_cases'] >= 0).all() assert df['date'].notnull().all()
STEP 04

Feature Engineering (Rolling Windows)

Computes 7-day rolling moving averages via transform to eliminate weekly calendar backlogs, alongside cumulative running totals.

df['rolling_7day'] = df.groupby('country')['new_cases'] \ .transform(lambda s: s.rolling(7, min_periods=1).mean()) df['cum_cases'] = df.groupby('country')['new_cases'].cumsum()
STEP 05

Statistical Analysis & GroupBy

Calculates Case Fatality Rate (CFR), population infection attack rate, and continent-level health performance metrics.

df['cfr'] = (df['total_deaths'] / df['total_cases']) * 100 summary = df.groupby('continent')[['new_cases', 'new_deaths']].sum()

💡 Problem Statement & Project Goal

The COVID-19 pandemic resulted in massive volumes of daily healthcare data requiring automated extraction, noise reduction, and actionable trend modeling. This project builds an end-to-end analytics workflow: Problem Statement → Dataset → Data Cleaning → Python Analysis → SQL Analysis → Dashboard → Key Insights → Conclusion.

🗄️ Dataset Specifications

  • Source: Our World in Data (WHO Epidemiological Timeseries).
  • Temporal Coverage: January 1, 2020 through December 31, 2023 (1,461 Calendar Days).
  • Attributes: Date, Country, ISO Code, Continent, Daily Cases, Cumulative Cases, Daily Deaths, Cumulative Deaths, Recovered, Active Cases, 7-Day Moving Averages, and Population.

⚙️ Technology Stack Flow

Python (Pandas, NumPy) → SQL Relational Modeling (SQLite / MySQL Window Functions) → Power BI & Interactive Web Dashboard.

✅ Verified Epidemiological Findings

  • Bimodal Wave Zeniths: Transmission peaked during the mid-2021 Delta wave and early-2022 Omicron wave (surpassing 3.4M daily cases).
  • Noise Filtering: 7-Day moving averages eliminate false weekend testing dips and Tuesday backlog surges.
  • Vaccination Decoupling: Case Fatality Rate fell by 89.9% (from 2.32% in 2020 to 0.23% in 2023), confirming vaccine efficacy against severe outcomes.
  • Geographic Burden: USA (106M) and India (44.7M) recorded the highest overall infection volumes.
